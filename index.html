This scanner runs a transparent, rule-based heuristic engine in your browser — the same categories of signal (destination type, TLD reputation, brand-domain mismatch, URL obfuscation, etc.) that a trained ML classifier would learn to weigh. It is a demonstration prototype for research/portfolio use, not a certified security product, and results should not be the sole basis for a real security decision.
